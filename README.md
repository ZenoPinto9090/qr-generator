# QR Code Generator

A small Flask website that turns any text or link into a QR code you can download as a PNG.

## Features
- Enter any text or URL
- Choose the file name
- Download the QR code as a PNG

## How to run

1. Install the requirements:

```
   pip install -r requirements.txt
```

2. Start the app:

```
   python app.py
```

3. Open http://127.0.0.1:5000 in your browser.

## Built with
- Python
- Flask
- qrcode
